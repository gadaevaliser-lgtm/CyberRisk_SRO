**СРО 2: Оркестрация мультиконтейнерной архитектуры в Docker Compose**

## 📂 Содержимое папки
* **`Гадаев Алишер СРО 2.docx`** — текстовый отчёт с описанием архитектуры, листингом конфигурации и скриншотами работы контейнеров.
* **`docker-compose.yml`** — файл декларативной конфигурации для оркестрации 5 независимых сервисов.
* **`apps/web/index.html`** — исходный код веб-интерфейса дашборда.

##  Архитектурный стек (5 контейнеров)

1. **`web` (Nginx):** Основной веб-сервер фронтенда (порт `8080`), обслуживающий пользовательский интерфейс.
2. **`calculator` (Python):** Микросервис выполнения вычислительных операций (порт `8082`).
3. **`counter` (Python):** Микросервис учёта и статистики обращений (порт `8083`).
4. **`cache` (Redis):** Высокопроизводительное хранилище данных в памяти для кеширования (порт `6379`).
5. **`database` (PostgreSQL):** Основная реляционная база данных для хранения информации (порт `5432`).
