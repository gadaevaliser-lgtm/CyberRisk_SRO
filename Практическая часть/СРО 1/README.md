**Отчёт по СРО 1: Развертывание веб-сервера в контейнере Docker**
В данном каталоге представлены материалы и результаты выполнения первой самостоятельной работы (СРО 1) по дисциплине «Киберриск и киберразведка».

https://lazy-hats-remain.loca.lt - ссылка на поднятый сайт

Содержимое папки
Гадаев Алишер СРО 1.docx — текстовый отчет о проделанной работе, включающий пошаговое описание настройки окружения и подтверждающие скриншоты.

index.html — исходный код кастомной HTML-страницы (кибер-дашборда), используемой в качестве целевого веб-приложения.

🛠 Краткое описание выполненных этапов
Подготовка окружения (Ubuntu & Docker):

Настройка виртуального окружения на базе ОС Ubuntu Linux.
Установка и конфигурация системы контейнеризации Docker для изоляции веб-сервисов.
Создание и локальный запуск приложения:
Разработка кастомной HTML/CSS-визитки (index.html) с адаптивным дизайном в кибернетической стилистике.
Развертывание официального легковесного веб-сервера Nginx в Docker-контейнере с пробросом портов и монтированием пользовательского файла через механизм томов (Volumes).
Успешная проверка работоспособности сервиса локально (http://localhost:8080).
Публикация в сеть (Альтернативное облачное развертывание):

В связи с временными техническими ограничениями шлюзов верификации облачной платформы AWS, задача по выводу сайта во внешний интернет была успешно реализована с использованием защищенных туннельных прокси-соединений (localtunnel).

Получена стабильная публичная ссылка для удаленного доступа к серверу из любой точки мира.
