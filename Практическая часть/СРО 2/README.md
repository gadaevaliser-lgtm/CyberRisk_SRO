**План для СРО 2: Что за 5 приложений мы поднимаем?**
Мы возьмем такие сервисы:

1.web — наш основной сайт-визитка (index.html + Nginx).
2.calculator — простое микроприложение на Python (Flask) с логикой калькулятора.
3.counter — сервис счетчика посещений на Python, который сохраняет данные.
4.redis — готовый легковесный образ кеширующей базы данных (redis:alpine).
5db — готовый легковесный образ реляционной базы данных (postgres:alpine).

Вся эта система будет запускаться одной командой: docker compose up -d.
