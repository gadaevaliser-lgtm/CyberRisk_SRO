## Навигация по репозиторию (Карта проекта)

Ниже представлена структура выполненных самостоятельных работ (СРО) по теории и практике.

### 📚 Теоретическая часть
Материалы и реферативные исследования по архитектуре систем и инфраструктуре:
1. **Из чего состоит физический сервер?** (Аппаратные компоненты, отказоустойчивость, уровни резервирования).
2. **Автоматизация гипервизора и виртуальных машин (IaC).** Инструменты Terraform, Ansible, а также стандарты OSI, Open Container Initiative (OCI) и спецификации образов.
3. **Архитектура Docker Engine.** Взаимодействие компонентов Docker daemon, Docker API, `runc` и системных пространств имен.

### 🛠 Практическая часть
Контейнеризированные решения и программные реализации:
* **СРО 1** — Развертывание одиночного веб-сервера (Nginx) в Docker-контейнере с пробросом портов и организацией публичного доступа через защищенные туннели (`localtunnel` в качестве альтернативы AWS, так как была проблема с сервисом). ссылка на сайт - https://lazy-hats-remain.loca.lt
* **СРО 2** — Оркестрация мультиконтейнерной инфраструктуры из 5 независимых сервисов с использованием `docker-compose` (веб-интерфейс, микросервисы Python, кэш Redis и реляционная СУБД PostgreSQL).
